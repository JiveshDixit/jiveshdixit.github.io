Understanding Variant Labels in CMIP5 and CMIP6 Ensembles

November 2026  |  Climate Modeling

In climate modeling projects like CMIP5 and CMIP6, variant labels are crucial for identifying specific simulations within large ensemble experiments. To systematically locate and distinguish these runs, specific global attributes have been defined:

  • Experiment ID: Identifies the root experiment for the simulation (e.g., historical, SSP scenarios like ssp126 or ssp245, dcppA-hindcast).
  • Sub-experiment ID: Specifies a sub-experiment within a defined ensemble (otherwise set to None). While undefined in CMIP5, it is heavily utilized in CMIP6, particularly for Decadal Climate Prediction Project (DCPP) experiments. For instance, in dcppA-hindcast experiments, s1961 denotes the initialization year.
  • Variant Label: A compound identifier built from distinct indices (Realization, Initialization, Physics, and Forcing) used to uniquely tag simulations from a single model's ensemble.

The Four Variant Indices

1. Realization Index (k ≥ 1): Distinguishes among ensemble members that differ solely in their temporal initialization point (e.g., branched from different points in a pre-industrial control run).

Note: Simulations with different forcing factors (e.g., natural vs. anthropogenic) that branch from the same point in time will share the same realization number. However, this rule has exceptions—such as DCPP experiments, which initialize annually but may reuse realization numbers across different start years. Crucially, sharing a realization number across different models does not guarantee they share an equivalent initialization point.

2. Initialization Index (l ≥ 1): Differentiates between various algorithms or observational datasets used to impose initial conditions on a forecast experiment. If only one method is used, it defaults to 1.

3. Physics Index (m ≥ 1): Identifies the physics version of the model. A single physics version is assigned 1. Consistency across all simulations of a particular model is strictly required.

Note: If a model features substantial physical differences from its baseline, it should ideally receive a new source_id, rather than just a different Physics Index. While CMIP5 relied solely on the above three indices, CMIP6 introduced a fourth index to capture forcing variations.

4. Forcing Index (n ≥ 1) [CMIP6 Only]: Distinguishes between runs that follow the standard protocol of a single experiment but apply different forcing datasets. For example, two historical simulations—one using CMIP6-recommended forcings and another using an alternative dataset—are differentiated by this index.

Summary: The Final Variant Label

The complete variant label is concatenated as r<k>i<l>p<m>f<n>. For example, a label of r2i1p3f233 translates to a Realization index of 2, Initialization index of 1, Physics index of 3, and Forcing index of 233.
