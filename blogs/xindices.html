xIndices: A Comprehensive Tool for Climate Variability Analysis

November 2026  |  Software Release

Climate change is one of the most pressing issues of our time, and understanding its effects requires sophisticated analytical tools. Presenting xIndices, a powerful, xarray-based Python library designed to compute Sea Surface Temperature (SST) trends, SST variability modes, and other atmospheric variability modes.

Tailored specifically for researchers and practitioners in climate science, xIndices simplifies the calculation of various climate variability indices and patterns, making it substantially easier to derive insights from complex, multi-dimensional Earth system datasets.

Key Features

  • Data Preprocessing: Supports multiple tools enabling users to load, regrid, and manipulate data with ease, fully integrated with methods defined by the Earth System Modeling Framework (ESMF).
  • Rotated EOF Analysis: Perform Empirical Orthogonal Function (EOF) analysis—both rotated (Varimax and Promax) and unrotated. This functionality allows users to examine EOF modes within user-defined regions, making it highly valuable for targeted spatial analyses.
  • Variety of Climate Variability Modes: Natively supports the calculation of major climate modes including the SST Warming mode, ENSO (El Niño-Southern Oscillation), PDO (Pacific Decadal Oscillation), AMO (Atlantic Multidecadal Oscillation), and NAO (North Atlantic Oscillation).
  • Parameter Controls for Variability Definitions: Extensive customization allows researchers to tailor definitions of variability. This flexibility is crucial for adapting the module to specific study requirements or unique regional climate characteristics.
  • Future Plans: More variability modes are planned for future updates to ensure the library stays relevant as new climate patterns are studied. We also plan to integrate comprehensive community support to drive extensive open-source development.

Installation

Getting started with xIndices is straightforward. You can install it via conda (recommended) or pip.

# Using conda (recommended):
conda create -n x_indices -c conda-forge python=3.11   ## (OPTIONAL)
conda activate x_indices
conda install -c jiveshdixit -c conda-forge xindices
# Using pip:
conda create -n x_indices -c conda-forge python=3.11 xesmf   ## (MANDATORY for dependencies)
conda activate x_indices
pip install xIndices
