Part 3: Physics First: Feature Selection and Leakage Prevention

November 2026  |  Feature Engineering

Data leakage occurs when information from outside the training dataset is used to create the model. This leads to wildly optimistic performance estimates that collapse in production.

Data Leakages and Prevention

  • Preprocessing Leakage: Fitting a scaler or imputer on the entire dataset before splitting. The test set mean and variance have now leaked into the training transformations.
  • Target Leakage: Including a feature that is a proxy for the target or is measured after the target event occurs.
  • Spatiotemporal Leakage: In gridded spatial data, adjacent grid cells are practically identical. If Cell A is in the train set and adjacent Cell B is in the test set, the model is learning to memorize local spatial patterns rather than generalize.

To prevent this, always use Pipelines to ensure transformations are strictly fitted only on the active training fold during cross-validation.

# Preventing Preprocessing Leakage with Pipelines from sklearn.pipeline import Pipeline from sklearn.preprocessing import StandardScaler from sklearn.ensemble import RandomForestRegressor pipeline = Pipeline([ ('scaler', StandardScaler()), ('model', RandomForestRegressor()) ])

Feature Selection: Guiding the Framework

Throwing hundreds of raw features into a neural network often degrades performance due to collinearity. A scientifically robust approach involves a two-step guiding process.

Step 1 Domain-Driven Selection: Before algorithms touch the data, pre-select predictors that have established physical or dynamical relationships with your target. This ensures the model searches for physically meaningful patterns rather than spurious statistical noise.

Step 2 Algorithmic Importance: Once a physically sound feature pool is established, use gradient boosting frameworks to rank feature importance and drop redundant covariates.

# Feature Selection using XGBoost Feature Importance import xgboost as xgb model = xgb.XGBRegressor(n_estimators=100, max_depth=4) model.fit(X_train, y_train) importance = model.feature_importances_ # Plot or threshold features based on importance scores
